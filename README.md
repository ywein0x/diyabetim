# Diyabetim

Diyabet hastaları için karbonhidrat sayımı ve insülin dozu hesaplama uygulaması (Android).

**İndir:** [Son sürüm](https://github.com/ywein0x/diyabetim/releases/latest) sayfasındaki `.apk` dosyasını telefonuna indirip kur. Uygulama yeni sürümleri kendisi kontrol eder ve tek dokunuşla günceller.

> Bu uygulama tıbbi bir cihaz değildir. Öneriler tahminidir; doz kararlarını doktorunun belirlediği ayarlarla ver.
